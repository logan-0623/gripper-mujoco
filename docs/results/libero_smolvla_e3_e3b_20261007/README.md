# E3 / E3b：进入抓取窗口时的偏差，以及能纠正多大的偏移

运行日期：2026-10-07 至 10-08，代码提交 `0812075`，服务器为 RTX 4080 SUPER。
- 脚本：[window_entry_probe.py](../../../scripts/window_entry_probe.py)；分析：[window_entry_analysis.py](../../../scripts/window_entry_analysis.py)。
- 运行记录：[run.log](run.log)。

## 要检验的推断

[E1/E2](../libero_smolvla_e1_e2_20261006/README.md) 得出的推断是：

> 10k 纠正不了自己接近物体时产生的偏差；25k 能在离物体最后约 10 cm 内把偏差纠正回来。

这里拆成两个可以直接测的问题：

- **E3：** 10k 进入抓取窗口时，偏差是否比 25k 大？偏差大小能否预测失败？
- **E3b：** 在窗口入口人为推偏夹爪后，哪个模型能纠正更大的偏移？

## 方法

- **单策略闭环评测。** 任务为 Spatial 0–3，每个任务取初态 0–19。评测命令、随机种子和步数上限都与能力时间轴相同。
- **窗口入口。** 定义为夹爪到目标表面距离首次 ≤ 0.10 m 的那一步，与 E2 的窗口起点相同。
- **E3 的偏差。** 在入口处记录"目标在夹爪坐标系下的位姿"（StateBank 的 `gripper_to_target` 口径）。再找同一任务 5 条演示各自的入口位姿：
  - 平移偏差 = 到最近一条演示入口的距离；
  - 旋转偏差 = 到所有演示入口中最小的测地角。
  - 作为尺度参照：演示之间按留一法计算的偏差为 0.2–3.9 cm、1–11°。
- **E3b 的推偏。** 进入窗口后，接下来 k 步的动作被替换为水平平移（动作幅度 1.0，夹爪保持张开），之后交还给策略。
  - 推动方向由（任务, 初态）决定，10k 和 25k 完全相同。
  - k = 0 / 4 / 8 / 12，实际推开距离的中位数分别为 0 / 2.3 / 5.2 / 8.3 cm。
- **配对的可行性。** 同一模型、同一初态在各个推偏档位下的入口位姿完全一致（80/80），因此各档之间可以严格按初态配对。

## 执行过程中的调整

- **推动幅度调大。** 冒烟测试中，动作幅度 0.3 推 4 步只移动了约 1.1 cm，落在演示之间的正常差异内。正式实验开始约 1 分钟后，改为幅度 1.0 重新开始；中断的那段运行放在 `aborted_push03/`，不计入结果。
- **推偏档位改为 4 / 8 / 12 步。** 幅度 1.0 下，推 4 步实测约 2.2 cm，所以第二批的档位由原定的 2 / 6 步改为 8 / 12 步。
- **第二批没有跑完。** 第二批到 05:30 被强制关机截断：四组都完整跑完了 task 0、1，task 2 只完成一部分，task 3 未开始。因此 E3b 只使用 task 0–1（每组 40 个回合）。task 1 正是 10k 和 25k 差距最大的任务。

## E3 结果（不推的两组，4 个任务，各 80 个回合）

| | 10k | 25k |
|---|---:|---:|
| 成功 | 50/80 | 69/80 |
| 进入窗口 | 80/80 | 80/80 |
| 入口平移偏差中位数 | 2.4 cm | 1.7 cm |
| 入口旋转偏差中位数 | 3.9° | 3.2° |
| 平移偏差预测失败的 AUROC | 0.69 | 0.70 |
| 旋转偏差预测失败的 AUROC | 0.58 | 0.47 |

- **10k 的入口偏差更大。** 同一初态下 10k − 25k 的配对差（CI 按初态聚类）：
  - 平移 +0.68 cm [+0.48, +0.89]；
  - 旋转 +0.63° [+0.43, +0.83]。
- **平移偏差能部分预测失败，旋转偏差基本不能。**
- **偏差不是全部原因。** 以 task 1 为例：10k 的入口偏差中位数 2.4 cm，只成功 5/20；25k 是 1.5 cm，成功 18/20。但 10k 在这个任务里，失败回合和成功回合的偏差差不多（2.5 cm 对 2.1 cm）。偏差本身，加上从偏差中纠正回来的能力，共同决定了结果。这一点由 E3b 直接检验。

## E3b 结果（task 0–1，每档 40 个回合）

| 推偏（实际距离） | 10k 成功 | 25k 成功 |
|---|---:|---:|
| 0 | 21/40 | 33/40 |
| 4 步（2.3 cm） | 16/40 | 32/40 |
| 8 步（5.2 cm） | 5/40 | 17/40 |
| 12 步（8.3 cm） | 2/40 | 11/40 |

10k 的基线本来就低，直接比较成功率的下降量会受地板效应影响。所以主要指标改为：**在不推就能成功的初态里，推偏后仍然成功的比例**。CI 按初态聚类。

| 推偏 | 10k | 25k |
|---|---:|---:|
| 2.3 cm | 12/21 = 0.57 [0.38, 0.76] | 29/33 = 0.88 [0.76, 0.97] |
| 5.2 cm | 4/21 = 0.19 [0.05, 0.38] | 13/33 = 0.39 [0.24, 0.55] |
| 8.3 cm | 1/21 = 0.05 [0.00, 0.14] | 8/33 = 0.24 [0.09, 0.39] |

再只看两个模型不推时都能成功的 15 个初态，做严格配对（25k 保住的 − 10k 保住的）：

| 推偏 | 10k 保住 | 25k 保住 | 配对差 [95% CI] |
|---|---:|---:|---:|
| 2.3 cm | 10/15 | 14/15 | +0.27 [+0.00, +0.53] |
| 5.2 cm | 2/15 | 8/15 | +0.40 [+0.07, +0.73] |
| 8.3 cm | 1/15 | 4/15 | +0.20 [−0.07, +0.47] |

## 结论

1. **E1/E2 的推断两部分都得到直接支持：**
   - 10k 进入窗口时偏差更大（+0.7 cm，+0.6°）；
   - 10k 能纠正的偏移范围也更窄。
2. **差别在"正常范围"内就已出现。** 2.3 cm 的推偏仍在演示之间的差异范围内，25k 几乎不受影响（保住 88%），10k 却丢掉 43% 的成功。
3. **10k 受两次损失：** 先是入口状态更差，再是对偏差的容忍度更低。这正是"能力形成 = 关键交互附近的吸引域变宽"的直接测量：在相同推偏下，25k 的成功保持曲线整体高于 10k。

## 局限

- 只有一个训练 seed。E3b 只用了 task 0–1；四个档位都完整的配对初态只有 15 个，CI 较宽。
- 推偏只沿水平方向平移，没有旋转扰动。
- 平移偏差预测失败的 AUROC 约 0.7，偏差只能解释部分失败。
- 每条闭环的逐步事件和完整的 `physical_events.json` 留在服务器上（`/root/autodl-tmp/smolvla-official-reproduction-v2/acquisition/e3_e3b_20261007/`）。本目录只保留入口元数据、逐回合结果和汇总。
