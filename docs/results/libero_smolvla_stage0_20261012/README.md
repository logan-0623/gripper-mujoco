## 结论

1. **F15 的"早期步承担"换了基点仍然成立。** 以 C@2500 为 base 时，前半段补回全部差距，后半段只补回 0.16。所以它不只是 10k 恰好处在振荡低谷的产物。但 C@2500 的学习率调度是重新预热的，这不能替代第二个训练 seed。
2. **"前半段有效"需要 25k 的 expert 和 25k 的 VLM 侧同时在场。**
   - 前半段：只换 expert 补回 0.54；再加上 25k 缓存，升到 0.89，增量显著。后半段加不加缓存，差别不显著。
   - 保持 10k 缓存时，前后两段的差别也不再显著；而全部 10 步都换 expert（X）能补回 0.91。
   - 所以 E6 中"expert 侧承担"和"前半段承担"是两个不同的切面，不能合并成"前半段的 expert 就够"。更准确的说法是：在前半段，两侧的组合起作用；如果只换 expert，就需要在所有 flow 步上换。
   - "阶段效应依赖缓存来源"这一交互只是趋势：两个阶段差 +0.09 与 +0.04 之间的差别没有单独检验。
3. **0c 定义的离线指标，不能定位"何时停止更新 VLM"。**
   - 高噪声段的 R 在 10k–25k 一直在 0.4–0.5 左右。而闭环中，10k 的 VLM 侧配 25k 的 expert 已经补回 0.91。离线的替换损失和闭环中的模块充分性不一致。
   - 按预注册，方法 1 不以这个指标进入阶段 2。
   - 如果继续做方法 1，指标需要先用闭环结果校准，例如直接用窗口内 X 组的补回比例作为标签。
4. **正常抓取与扰动恢复：** 在相同的 43 个初态上，前半段替换对推 8 步后的成功没有带来增量（0.00）。但 CI 是 ±0.14，远不够窄，不能主张两者分离，只能作为待扩样本的线索。

## 不能推出

- 只有一个训练 seed。0b 的基点 C@2500 来自重新预热的调度。
- E6c 没有对"阶段 × 缓存"的交互做单独检验。
- 0c 只覆盖 Spatial 0–3 的窗口帧，时间抽样是均匀的（训练时用 Beta(1.5, 1)），Δ 固定为 5k；没有 5k 的闭环 X 组。
- 匹配保持率只有 43 个初态。
