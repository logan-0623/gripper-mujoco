# 研究问题：VLA 在训练中到底学会了什么

更新：2026-10-11（同步换指令评测与 E4/E5 进展）。依据 [findings.md](findings.md) 中已确立的事实。原先"VLA 何时学会依据动作结果调整"那份草案已经被本文件取代，旧稿保存在 git 标签 `pre-restructure`。

## 一个好问题要满足什么

1. **有两个都说得通的答案，并且它们对同一个实验给出相反预测。** 不满足这一点，任何结果都能被解释，也就得不到 yes 或 no。
2. **判决量是行为：** 闭环成功率，或者训练改动带来的效果。探针准确率、千分位级的 RMS 差只能当测量工具，不能当判决。
3. **两种答案都会改变别人的做法。** 例如决定训练预算花在哪个模块上、要采什么数据、选什么优化器。
4. **用现有资产就能先做第一刀：** 同谱系的五个 checkpoint、StateBank、flow trace、强制掉落的分叉框架。

过去两个月的实验，大多卡在第 1 和第 2 条上。问题都是"信息在不在、有没有被用"。结果总是"能读出，但编辑它的效果不比随机方向强"，这个结论两种解释都能接受。

## 故事线（待检验的假设）

> **假设：VLA 先"知道"、后"会做"。在能力形成的约 10k 步里，与任务相关的内部信息早已可读，真正变化的是两件事：表示的稳健性和可用性，以及策略被推离轨迹后能否回来。**

先说明这条故事线现在的证据基础。此前支持它的两条证据，"Contact 可读性不变"和"语义干预不超过随机"，经审计都不能使用：前者测的是输入变量，而且指标已经饱和；后者的干预点或者没有观测通路，或者力度不足。详见 [审计](notes/probe-intervention-audit-20261005.md)。所以 **Q0 必须先做**：用正确的测量重新检验"知道"这一半。

这条故事线在 LLM 中有直接的对应：
- **探针饱和：** 探针准确率在预训练的前几千步就饱和，之后的表示变化对它不可见；表示的脆弱度（fragility）却会持续变化（Reblitz-Richardson, 2026）。
- **能读不等于能用：** π₀.₅ 的任务进度可以线性读出，但用同一个探针方向无法驱动策略（Bhardwaj et al., 2026）。
- **反例：** 在 MLM 中，句法注意结构先突然出现，随后语言能力才出现；在训练中抑制这个结构会推迟能力（Chen et al., 2024）。

我们要回答的是：VLA 属于"一直可读、靠稳健性和使用方式的改变获得能力"，还是属于"先形成结构、再获得能力"。

## Q0. 用正确的测量重新检验"知道先于会做"

### Q0a：可读性饱和之后，脆弱度是否还在跟随能力变化？
- **目标变量：** 不再用 Contact，改用**输入中没有直接给出**的变量，例如物体是否已离开桌面且在手中、物体相对夹爪的位姿、任务进度、下一阶段的动作类别。并始终以"本体状态 + 时间"为条件。
- **指标：** 除准确率外，再测两个量。
  - **脆弱度：** 往激活里加噪声，探针准确率开始崩溃时的噪声水平。
  - **分类间隔。**
- **数据：** 用已有 flow trace，不对 token 取平均，每个 stage 分开测。验证集至少 10 条独立 episode。
- **判据：** 若准确率从 5k 起就平台化，而脆弱度在 5k→15k 期间随成功率上升（看 episode 级 CI），则"知道"这一半成立，同时说明能力伴随着表示稳健性的提高。若脆弱度也平坦，则表示层面在这段时间没有可测的变化。

### Q0b：抓或放的决定在 flow 采样的第几步就已经确定？（借鉴扩散模型）
- **扩散模型的经验：** 文生图模型的整体构图在第一个去噪步之前就可以预测。构图类干预只在早期步有效，在后期步无效；风格可以在中期步修改（Tinaz et al., NeurIPS 2025）。
- **对应到 SmolVLA：** 夹爪的开合决定可能也在早期 stage 就已确定。如果是这样，旧干预只在最后一步施加，是设计上看不到效应的原因。
- **实验：** 取 Contact 与非 Contact 配对状态，在第 k 个 stage 把 expert 激活或 x_t 从一个状态换成另一个（activation patching），看最终夹爪命令是否随之翻转，并对 k = 0…9 逐一扫描。
- **判据：** 存在一个"决定 stage"k*：在 k* 之前替换能翻转决定，之后不能。可以进一步比较 k* 是否随训练提前或变得更清晰，这是一个可以随训练追踪的结构量。
- **价值：** 如果 k* 很早就确定，推理时可以只在早期 stage 做引导；训练时也可以对早期 stage 加权。

### Q0c：用正确的方式重做"是否使用"
- **方法：** LEACE 或均值投影做全层擦除（Belrose et al., 2023；Dobrzeniecka et al., 2025），或在 Q0b 找到的 stage 上做跨状态激活替换。
- **度量：** 剂量—反应曲线，最后用闭环成功率判决。
- **判据：** 擦除"物体在手中"信息后，搬运阶段的闭环成功率下降，且下降幅度明显大于同秩随机擦除（看 episode 级 CI）。

## Q1. 能力形成发生在哪个模块：VLM、动作专家，还是两者之间的接口？

**两种世界**
- **A（读出 / 执行侧）：** 5k 到 25k 的收益主要在 action expert 和投影层里。VLM 在 5k 时已经够用。
- **B（表征侧）：** 收益主要来自 VLM 和视觉编码器的变化（这个谱系是全量微调，VLM 确实在更新）。
- **C（共适应）：** 两侧的变化离不开对方，任何拼接都会崩。

**判决实验：跨 checkpoint 的模块移植，不需要训练。** 同一谱系从同一初始化出发，参数名完全一致，可以直接拼成混合模型：

| 组合 | 视觉 + VLM | expert + 投影层 |
|---|---|---|
| H1 | 5k | 25k |
| H2 | 25k | 5k |
| 对照 | 5k / 25k 原模型 | — |

在已有的 40 个配对初态（Spatial 0–3）上测闭环成功率。之后可以细分到视觉编码器、VLM 文本层、state_proj，以及 expert 读取 VLM KV 的那一层。

**Yes/No 判据（需预注册）**
- H1 达到 25k 成功率的 80% 以上（看 CI 下界），且 H2 接近 5k → 支持 A。
- 反过来 → 支持 B。
- H1 和 H2 都低于 5k → 支持 C，能力存在于接口的协同变化里。

**重要在哪里**
- 如果结论是 A，那么"VLM 语义没被用好"至少不是这个阶段的瓶颈。
- 如果结论是 C，那么 Knowledge Insulation 这类"阻断 expert 向 VLM 回传梯度"的做法，代价要重新评估。（KI 不等于冻结 VLM：主干仍通过离散动作 token 等目标更新，只是不接收 expert 的梯度。）
- Muon 等优化方向也知道该优先作用在哪个模块。

**成本与风险**
- 成本：每个组合跑 40 条 rollout，和现有时间轴评测的成本相同。
- 风险：模型拼接（model stitching）在 LLM 中已有先例。新意在于把它沿 VLA 训练时间轴展开，并用闭环成功率作为判据。立项前需要检索 VLA 方向的近邻工作。

## Q2. 5k 的失败来自"动作本身不对"，还是"小误差在闭环中累积"？

**两种世界**
- **A（累积误差）：** 在演示轨迹上的状态里，5k 与 25k 的单步动作误差相差不大。差距在闭环中被放大：5k 一旦偏离，就回不来。
- **B（单步就错）：** 即使在演示状态上，5k 的动作也明显更差，尤其是夹爪时机。

**判决实验（第一步零新增算力）**
1. 用已有 flow trace（512 个 StateBank 状态，五个 checkpoint 共用同样的状态和噪声），计算每个 checkpoint 实际执行的前 10 步动作与演示动作的误差，按阶段拆开（接近、抓取、搬运）。
2. **教师纠正 rollout：** 让 5k 策略执行，每隔 k 步把仿真状态重置回演示轨迹。观察成功率随 k 的变化。如果 k 很小时 5k 接近 25k，误差累积就是主要原因。

**Yes/No 判据（需预注册）**
- 演示状态上的离线误差差距不到闭环差距的一半，且教师纠正能恢复大部分成功率 → A。
- 离线误差已经能解释成功率的排序 → B。

**重要在哪里**
- 这是 BC 理论（compounding error）在 VLA 训练动态上的直接检验。
- 如果是 A：离线 loss 和探针都看不到能力形成，评估训练进度必须用闭环指标或吸引域指标；DAgger 类数据和扰动增强应该能加速能力形成。
- 如果是 B：问题回到"单步动作质量"，Q1 的定位更关键。

## Q3. 能力可以用"吸引域宽度"来度量吗？吸引域宽度在训练中如何变化？

**定义：** 在固定的扰动族下（强制张开夹爪、把物体平移 δ、把末端位置偏移 δ），策略仍能完成任务的最大扰动幅度。

**两种世界**
- **A：** 吸引域宽度随训练单调变宽，并且比离线 loss、探针指标更能预测每个任务的成功率。这也能解释 F1 中非单调的逐任务曲线。
- **B：** 吸引域宽度与成功率无关，或者早期就饱和了。

**实验**
- 在已有的分叉框架（`scripts/feedback_branch_pilot.py`）上扩展扰动族和扰动幅度。
- 每个 checkpoint、每个任务各画一条"扰动幅度—成功率"曲线。
- 用 5k、10k、25k 和留出初态做预注册检验。

**Yes/No 判据：** 在留出的任务和 checkpoint 组合上，吸引域宽度对成功率的秩相关明显高于离线动作误差（比较两者相关系数之差的 CI）。

**重要在哪里**
- 这把"可解释性"从"找特征"转为"测量一个控制论意义上的量"。
- 如果成立，它就是一个能复用到其他 VLA 的能力诊断工具。
- F6 中 Spatial 0 和 Spatial 1 的反差是第一个数据点。

## Q4. 内部表示能否提前预测"策略即将离开吸引域"？

**这一步才需要可解释性。** 在 Q3 的扰动 rollout 中，记录扰动后的隐藏状态，问一个问题：能否在失败发生之前，从隐藏状态判断这次会不会恢复？

**两种世界**
- **A：** 存在一个可读的"偏离信号"，并且它在 VLM 侧和 expert 侧的位置可以定位。
- **B：** 隐藏状态只能反映当前的物理状态（F2 已经看到这一点），预测不了能否恢复。这时恢复与否取决于动作映射在未见状态上的泛化，和表征无关。

**判决：** 按 episode 划分训练集与测试集，比较两种预测器的 AUROC：
- 只用"本体状态 + 时间 + 物体位姿"的预测器（F2 告诉我们这个基线很强）。
- 在此基础上再加入隐藏状态的预测器。

增量的 CI 大于 0 → A；否则 → B。

**关于近邻工作：** 已有工作用 VLA 特征做失败检测（例如 SAFE 和 FailPatch，均需核对原文）。本问题的区别在于以吸引域为标签，并且与本体基线做条件比较。

## Q5. 针对吸引域边缘的训练，能否用更少的步数达到同样的能力？

**这一步把诊断变成性能收益。**

**比较对象（相同的步数、数据量和算力）**
1. 原配方继续训练。
2. 加入扰动后由脚本控制器恢复的示范（恢复数据）。
3. 只加入动作噪声增强（DART 风格）。

主指标是"达到 80% 成功率所需步数"和吸引域宽度，并在留出任务上检验。

**Yes/No 判据：** 第 2 组或第 3 组在达到同样成功率时节省 ≥30% 的步数（CI 下界），且正常任务的成功率不下降。

**Muon 的位置：** 在这个框架里，优化器问题可以改写成"在相同步数下，哪个优化器让吸引域变宽得更快"。这比"Muon 是否让 loss 降得更快"更有信息量。但它应该放在 Q5 之后，作为一个比较维度，而不是作为主问题。

### E6（预注册）：抓取窗口内，10k→25k 的差距由哪些 flow 步、哪一侧承担？

- **脚本：** [flow_stage_mix.py](../scripts/flow_stage_mix.py)。10k 与 25k 同步运行，窗口外始终由 10k 执行；窗口（同 E2：距目标 ≤ 10 cm 到稳定抓起并抬高 2 cm）内，10k 的动作块由混合速度场积分得到：第 k 个 flow 步（共 10 步，k=0 为纯噪声端）用哪个模型的 expert、读哪个模型的前缀缓存（VLM 侧，含状态投影）由组别决定。两模型共用同一观测和同一初始噪声。混合在窗口打开后计算的第一个动作块生效，各组时机相同。等价性已检查：全 10k、全 25k 两组与原模型输出逐元素一致。
- **组别：** N = 全 10k；A = 全 25k（E2 的同路径版本）；E = 第 0–4 步用 25k；L = 第 5–9 步用 25k；V = 25k 的 VLM 侧 + 10k expert；X = 10k 的 VLM 侧 + 25k expert。
- **评测：** 不推：6 组 × Spatial 0–3 × 初态 0–39（每组 160 个回合）。推 8 步（同 E3b，幅度 1.0）：N、A、E、L 四组 × task 0–3 × 初态 0–19（每组 80 个回合）。同时补跑 E3b 的 task 2–3（10k、25k 单独评测，推 8 步）。
- **主指标：** 不推成功率；补回比例 = (组 − N) / (A − N)。按（任务, 初态）配对 bootstrap 95% CI。
- **判据：**
  - **早期步承担（F7 的机制在闭环里起作用）：** E − L 的 CI 下界 > 0，且 E 的补回比例 ≥ 2/3。
  - **后期步承担：** L − E 的 CI 下界 > 0，且 L 的补回比例 ≥ 2/3。
  - **分布式：** E、L 的补回比例都 < 2/3，且 E − L 的 CI 包含 0。
  - **前提：** A − N 的 CI 下界 > 0（窗口内差距可测）；否则 E6 不作判决。
  - 推 8 步的保持率作为次要指标，按同样方式比较 E 与 L。
  - V 与 X 是 F10 在窗口内的闭环版本，只做描述，不预设判据。

**E6 已完成**（2026-10-12，[归档](results/libero_smolvla_e6_20261012/README.md)，结论见 F15）：满足"早期步承担"判据（E − L = +0.09 [+0.03, +0.16]，E 补回 0.89）；窗口内 expert 侧补回 0.91，VLM 侧 0.43。E3b 已补齐到 task 0–3。

## 阶段 0–1 预注册（2026-10-12，运行前写定）

**总原则**

### E6c：flow 阶段 × VLM 侧的交叉（排在阶段 0 最前）

**为什么要做**
- E6 的 E 组用的是 `--kv own`：前半段既换了 25k 的 expert，也换了 25k 的前缀缓存。X 组则是全部 flow 步都换 25k 的 expert、缓存保持 10k。
- 所以"只在前半段换 expert 就够了"这一点还没有直接证据。

**新增两组（保持 10k 缓存，只换 expert）**
- **XE：** `--donor-stages 0-4 --kv base`。
- **XL：** `--donor-stages 5-9 --kv base`。
- 与 E6 的 E、L 组合成 2×2：flow 阶段（前/后）× VLM 侧（25k/10k）。
- 规模同 E6：Spatial 0–3 × 初态 0–39，不推，与 E6 的 N/A 配对。

**判据**
- **前半段 expert 足够：** XE 补回 ≥ 2/3，且 XE − XL 的 CI 下界 > 0。
- **需要协同：** XE 补回 < 1/3，而 E 的补回是 0.89。说明前半段的作用依赖 25k 的 VLM 侧。
- **介于两者之间：** 只做描述。
- **措辞约束：** 补回比例一律写成"补回本实验定义的差距"，不解释为某个模块储存了多少能力。

**同时离线重算 E6 的保持率**
- 只用 N/A/E/L 四组不推都成功的初态，用同一批初态比较推 8 步后的结果，代替各组用各自分母的保持率。
- 只做描述。要主张"正常抓取和扰动恢复由不同变化承担"，需要等价区间足够窄；按现有规模大概率不够，结论待扩样本。

**阶段 0 第一批已完成**（2026-10-12，[归档](results/libero_smolvla_stage0_20261012/README.md)，结论见 F16、F17）：
- **E6c：** 落在中间区。前半段只换 expert 补回 0.54，加上 25k 缓存升到 0.89。
- **0b：** "早期步承担"在 C@2500 基点上成立。
- **0c：** 预测不成立。高噪声段的 R 始终约 0.4，离线指标与闭环不一致，方法 1 不以此指标进入阶段 2。

### 0a：E7，初始噪声在早期 flow 步中的残余作用

**假设**
- 10k 的动作块粗结构仍由初始噪声决定，早期 flow 步没有把它拉回观测，于是带着偏移进入抓取窗口。
- 25k 的早期步由观测驱动。
- 这把 F7（观测在第 3–4 步的纠正力增强）和 F15（前半段 flow 承担差距）连成一个机制。

**离线指标**
- **数据：**
  - 固定 256 帧窗口帧，按 E4 的定义取（第一次合夹爪命令前 20 帧到后 25 帧），来自 Spatial 0–3 的演示。
  - 所有 checkpoint 用同一组帧、同一组 16 个噪声样本。
- **噪声主导比：**
  - D(c) = 每帧在 16 个噪声样本之间的执行动作方差，再对帧取平均，作分子；
  - 各帧的噪声平均动作在帧之间的方差，作分母；
  - 只取实际执行的前 n_action_steps 步。
- **预测：**
  - D 在 5k→25k 单调下降；
  - D(10k) − D(25k) 的 CI 下界 > 0（按帧 bootstrap）。

**闭环干预**
- **做法：** 初始噪声乘以 σ ∈ {1, 0.5, 0}。
- **组别：**
  - 10k、25k 各跑 3 个 σ，整条 episode 都缩放；
  - 另加一组：10k，σ = 0，只在窗口内缩放。
- **规模：** Spatial 0–3，初态 0–39，每组 160 个回合。
- **指标：**
  - 差距闭合 G(σ) = (S₁₀ₖ(σ) − S₁₀ₖ(1)) / (S₂₅ₖ(1) − S₁₀ₖ(1))；
  - 另记 E3 的进窗口偏移。

**判据**
- **噪声主导（支持机制）：**
  - 某个 σ < 1 满足：S₁₀ₖ(σ) − S₁₀ₖ(1) 的 CI 下界 > 0，且 G(σ) ≥ 0.5；
  - 25k 在同一个 σ 下的变化 CI 包含 0；
  - 10k 的进窗口偏移随 σ 下降。
- **读出不足（否定机制）：** 10k 在所有 σ 下的变化 CI 都包含 0，或者为负。
- **普遍去噪收益（不支持特异机制）：** 10k 和 25k 都显著提升，且两者提升之差的 CI 包含 0。
- **局限：** σ = 0 时起点固定在原点，对 flow 而言可能偏离训练分布（高维下范数不典型），所以以 σ = 0.5 为主。
- **代码：** `flow_stage_mix.py --donor-stages none --noise-scale σ [--noise-scope window]`。噪声先采样再缩放，各组随机数用法相同。

### 0b：E6 稳健性检查，排除 10k 恰好处于振荡低谷

- **原因：** Block et al. 指出，单个 checkpoint 的比较可能受 SGD 噪声振荡影响。
- **做法：** 用 E4 的 C@2500 代替 10k 作为 base（不推 57/80，10k 是 50/80，25k 是 69/80），重跑 E6 的 N/A/E/L。规模同 E6。
- **注意：** C 是从 10k 起重新预热的学习率调度，不等同于原谱系的 12.5k。它只回答"换一个相邻的基点后，结论是否还成立"。
- **判据：**
  - **成立：** 沿用 E6 的"早期步承担"判据，A − N 的 CI 下界 > 0 时才判决。
  - **不成立：** E 的补回比例 < 1/3，或者 L − E 的 CI 下界 > 0。这说明 F15 依赖 10k 这一个点。

### 0c：方法 1 的指标——VLM 侧何时不再承担差距（离线，现有谱系）

- **脚本：** [vlm_share.py](../scripts/vlm_share.py)。速度走 `denoise_step`，读 E6 的前缀缓存路径。已在本地核对：同一模型下，这条路径的损失与训练 `forward` 的损失逐元素相同。

**依据**
- F10：5k↔25k 整条 episode 的移植，需要两侧都换。
- F15：窗口内，10k 的 VLM 侧配 25k 的 expert，补回 0.91。
- E4：从 10k 起，只训 expert 的 LoRA（LE）在 5000 步与全量微调（C）持平，都是 66/80。
- **假设（未证实）：** 在 5k 到 10k 之间存在一个点，过了它全量微调对 VLM 的更新不再必要。方法 1 要在训练中在线找到这个点。
- **这三条不足以定位切换点：**
  - F10 和 F15 同时改变了时间（5k 对 10k）和干预范围（整条 episode 对窗口内），不能据此推出转折点在哪里。
  - LE 和 C 的差别不只是冻结 VLM：LE 同时改变了 LoRA、可训练模块和窗口加权（×3）。
  - 离线替换损失衡量的是模块之间的兼容性。它能否预测"从此冻结后的训练表现"，要靠阶段 2 的冻结对比单独验证。
- **报告方式：** 主报告 M_V、M_E 各自的值和 CI。R 只作辅助：模块之间有交互，损失差可能为负，分母也可能接近 0；不把 R 称为"贡献份额"。

**定义**
- **L_w(E, V)：** 在固定的窗口帧集合上（同 0a，另留 256 帧做 held-out），expert E 读取 VLM 侧 V（含状态投影，同 E6）的前缀时的 flow-matching 损失。
  - 时间只取高噪声半段 τ ∈ [0.5, 1]（SmolVLA 中 τ = 1 是纯噪声），对应 F15 的前半段 flow。
  - 噪声和 τ 的抽样在所有评估之间共用。
- **VLM 侧的边际贡献：** M_V(c) = [L_w(E_c, V_{c−Δ}) − L_w(E_c, V_c)] / L_w(E_c, V_c)
- **expert 侧的边际贡献：** M_E(c) = [L_w(E_{c−Δ}, V_c) − L_w(E_c, V_c)] / L_w(E_c, V_c)
- **VLM 份额：** R(c) = M_V / (M_V + M_E)
- **切换点：** s* = 第一个连续两次满足 R < ρ 的 checkpoint，预设 ρ = 0.25。
- **对照指标：** 同样的量取低噪声半段 τ ∈ [0, 0.5) 计算，记为 R_low。

**现有谱系上的检验**
- **离线：** Δ = 5k，c = 5k…25k。5k 的上一个点用初始化权重（smolvla_base），前提是服务器缓存里有。
- **闭环：** 新增 5k 的窗口内 X 组，即 base = 5k、donor = 25k，加上 `--donor-stages all --kv base`，同时跑 N 和 A 两组，规模同 E6。
- **预测：**
  1. R(5k) ≥ ρ > R(10k)，即切换点落在 (5k, 10k]。
  2. 闭环 X 的补回比例：5k 低于 2/3，10k 是 0.91（已有）。
  3. R 比 R_low 更早越过 ρ。如果两者一样，说明 flow 阶段的限定没有带来信息。
- **局限：** 现有谱系只有 5 个 checkpoint，闭环可比的只有 5k 和 10k 两个点（15k 与 25k 的差距不可测），所以这里只算可行性检验。真正的检验在阶段 2：用密集 checkpoint 的 π0 谱系，以及按 s* 切换训练的对比。

### 0e：OOD 扰动基准（以 LIBERO-Plus 为主，LIBERO-PRO 为辅）

**前置检查（不通过则本节不判决）**
- 基准的场景资源和初态能否接入 lerobot 的 `LiberoEnv`、我们的事件记录器和窗口逻辑。
- 布局扰动下，目标物体的身份能否重新映射。
- 扰动维度以其仓库实际提供的为准，核对后写入归档。

**模型**
- 我们的 5k–25k；官方 SmolVLA。
- π0.5 官方 LIBERO checkpoint，只作外部参照，不进判据。

**维度分组（运行前固定）**
- **机械类 M：** 机器人初始状态、物体布局/位置。吸引域和早期纠偏应当在这一类起作用。
- **视觉类 V：** 光照、背景纹理、传感器噪声。
- **相机视角：** 两种解释都可能，只做描述。
- **语言类：** 单独报告。

**指标**
- 保持率 r_d(c) = 维度 d 下的成功率 / 同一批任务无扰动的成功率。
- Δr_d = r_d(25k) − r_d(10k)。同一批扰动回合在不同 checkpoint 之间配对。
- 每个维度、每个 checkpoint 至少 160 个回合。

**判据**
- **支持机制：** Δr_M 的 CI 下界 > 0，且 Δr_M − Δr_V 的 CI 下界 > 0。
- **只是整体变强：** Δr_M、Δr_V 都 > 0，但两者之差的 CI 包含 0。
- **语言维度的预测（来自 F13）：** 我们所有 checkpoint 和官方 SmolVLA 的 r_L ≤ 0.35，与文献中报告的 π0 系列"对指令不敏感"相反。只做跨模型描述，不算方法优势。
- **因果追加（只在"支持机制"时做）：** 在 M 类扰动下跑 E6 的 E 组。补回比例 ≥ 2/3 时，说明 OOD 下的差距也由前半段 flow 承担。

### 0f：E8，推理时自引导——沿训练方向外推 10k，能否不训练就补回差距？

**来源**
- Karras et al., *Guiding a diffusion model with a bad version of itself*（NeurIPS 2024, arXiv 2406.02507）：用同一模型较差的版本做引导，v = v_弱 + w·(v_强 − v_弱)。
- 我们的谱系里有天然的"较差版本"：较早的 checkpoint。

**假设**
- E6 和 F16 把差距定位在前半段 flow 步的速度场，并且需要两侧组合。
- 自引导时两个模型都带完整的 VLM 侧和 expert，因此满足 F16。
- 如果 10k→25k 的变化大体延续 5k→10k 的方向，那么在前半段用 5k 引导 10k（w > 1），应当补回一部分窗口内差距。

**组别**
- 窗口内引导，窗口外由 10k 单独执行。
- 每个 flow 步上，两个模型各读自己的前缀缓存。

| 组 | 弱模型 | 引导的 flow 步 | w | 作用 |
|---|---|---|---|---|
| **G1** | 5k | 0–4 | 2 | 主组 |
| G2 | 5k | 0–4 | 1.5 | 描述 |
| G3 | 5k | 全部 10 步 | 2 | 阶段特异性 |
| G4 | 15k | 0–4 | 2 | 方向对照：远离 15k，即逆训练方向外推 |

- **规模：** Spatial 0–3，初态 0–39，每组 160 个回合。
- **对照：** N、A 沿用 E6，它们的随机数用法与本实验相同。
- **冒烟检查（不判决）：** w = 1 时，task 0、初态 0–9 的结果应与 N 一致（只有浮点差）。
- **代码：** `flow_stage_mix.py --donor <弱模型> --donor-stages 0-4 --kv own --guide-weight w`。

**判据**（补回比例 = (组 − N) / (A − N)）
- **外推有效：** G1 − N 的 CI 下界 > 0，且 G1 补回 ≥ 1/3；若补回 ≥ 2/3，记为强。
- **前半段特异：** G1 − G3 的 CI 下界 > 0。
  - 若 G3 ≥ G1 且差的 CI 包含 0，说明引导不分阶段，只做描述。
- **方向特异：** 要求 G1 − G4 的 CI 下界 > 0。
  - 若 G4 − N 的 CI 下界也 > 0，说明收益来自一般的"锐化"或扰动，而不是训练方向，不主张方向解释。
- **否定：** G1 和 G2 的 − N 的 CI 都包含 0 或为负。结论是在速度场上，5k→10k 的方向不能局部外推到 25k。
- **w 的多重比较：** 只有 G1 进判据。w 不在评测集上调。

**局限与后续**
- 只在窗口内引导。窗口依赖特权信息，所以这还不是可部署的方法。
- 外推有效时，下一步：
  - 在 Spatial 4–9 上用同一个 w 复测，作为 held-out；
  - 改成整条 episode 都引导，再与 25k 比较。
  这两步通过之前，不称为方法。
- w 过大时动作可能抖动或过冲。本实验只记录成功率，不评估动作质量。

### seed 2000 复现（2026-10-14，运行前写定）

- **冒烟检查：** E8 的 w = 1（task 0，10 个回合）应与 N 的相同初态结果一致，只核对代码。

### 阶段 1：Long（`libero_10`）——机制是否只适用于单次抓放

**前置工程**
- `GraspWindow` 改为窗口序列：每个抓放子目标一个窗口，各有自己的目标物体。
- 注册表加入 `libero_10` 的有序子目标。
- **任务选择规则：** 读 BDDL，只选子目标全是抓放、没有铰接操作的任务。名单在运行前随注册表一起提交。

**流程**
- **门槛：** 10k 对 25k，所选任务 × 初态 0–39。
- **记录：**
  - 每个回合完成到第几个子目标；
  - 失败发生的位置：在第 k 个窗口内，还是在窗口之间。
- **组别：**
  - N、A；
  - W_all：所有窗口内都用 25k，即 E2 在 Long 上的版本；
  - E、L：所有窗口内只换前半段或后半段 flow；
  - 描述性的两组：只在第 1 个窗口用 25k，只在第 2 个窗口用 25k。

**判据**
- **窗口机制覆盖 Long：** W_all 补回 ≥ 2/3；E − L 的 CI 下界 > 0，且 E 补回 ≥ 2/3。
- **不覆盖：** 满足以下任一条：
  - W_all 补回 < 1/3；
  - 在"25k 成功、10k 失败"的回合中，≥ 50% 的失败发生在窗口之外。
  - 无论哪种都是有效结果：说明 F15 刻画的是单次抓取的形成，多阶段衔接是另一种能力。
- **描述性预测：** 误差会累积，所以 10k 在第 2 个窗口的进窗口偏移大于第 1 个窗口（E3 的指标逐个窗口计算）。

**Goal（铰接任务）放到阶段 3：** 那里的窗口要改用"夹爪到把手的距离"来定义，并与抓放任务分开统计。

## 从第二批论文得到的修正

1. **逐 token 处理，不再做平均池化。** 我们所有探针和干预都在 50 个动作 token 上取了平均。Action Atlas 已经证明这会丢失动作所需的信息。
2. **干预后要检查下游是否接住了信号。** 在 flow trace 里测：注入后，下游层和后续 stage 的读出是否随之改变。
3. **用"目标区间 + 最小范数"的控制取代固定剂量。** 这是 Buurmeijer et al. 的做法，并且每次推理都施加。Q0c 应以此为主要方法。
4. **SAE 或重建的质量要用"替换回原模型后的闭环成功率"来评估，不能看 MSE。** Action Atlas 与 SALT 给出了同样的教训：重建好不代表功能保留。
5. **探针目标改为非输入变量。** 按 OpenVLA 世界表示一文的做法，用未来状态变化 Δ(t→t+K)，以及物体相对位姿的变化。

## Q6（新增）：重建与结构约束是诊断工具，还是加速训练的手段？

可以从两个方向借鉴"重建"：

### Q6a：诊断，测一个不会饱和的结构量
- **对象：** 各 checkpoint 隐藏状态的时间代数结构。
- **ALAM 式指标：**
  - 可加性：Δh(t→t+2) 是否约等于 Δh(t→t+1) + Δh(t+1→t+2)。
  - 可逆性：正向与反向转移是否互为相反。
- **SALT 式指标：** 能否从 expert 隐藏状态解码指令中的动词。
- **两种世界：**
  - 这些结构量在 5k→15k 期间随能力上升而变好。这就是"知道"之外的"组织方式在变"，可以和 Q0a 的脆弱度互相印证。
  - 结构量不变，或者动词可解码性随训练下降，后者对应 SALT 说的语义侵蚀。
- **判据：** 结构量与逐任务成功率的相关性，显著高于线性探针准确率与成功率的相关性（看 episode 级 CI）。

### Q6b：干预训练，辅助重建目标能否加速能力形成
- **做法：** 在相同步数下比较三组：
  1. 原配方。
  2. 加 LaMP 式的未来场景流辅助预测。
  3. 加 ALAM 式的潜在动作一致性约束。
- **主指标：** 达到 80% 成功率所需步数，以及 Q3 的吸引域宽度。
- **判据：** 若第 2 或第 3 组节省 ≥30% 的步数，说明"缺少关于未来的结构"是能力形成的瓶颈。这正好对应你最初关心的"结构化输入、特征提取"方向，并且能用 Q6a 的诊断量解释为什么有效。
- **成本：** 需要训练，放在 Q0–Q2 之后。
