# VLA 何时学会依据动作结果调整下一步？

日期：2026-10-04。状态：候选研究问题与实验草案；尚未验证假设。依据：CCFA idea optimizer、literature searcher、experiment designer；本次进行公开文献核对、已有文件检查和方案设计，没有启动训练、策略评测或干预，也没有修改 `ccfa.yaml` 的实验门禁。

## 1. 推荐问题

**在训练数据覆盖、输入能够观察到的操作分叉上，VLA 是否先形成对动作结果的可辨识表示，随后才学会利用这些信息调整动作？这种转化的滞后是否构成一个可修复的性能瓶颈？**

具体起点是抓取后的决策：同一个目标、相近的动作历史，实际抓住目标时应继续搬运；抓空或滑落时应重新接近、调整并抓取。需要检验模型是否依据实际结果选择后续行为，以及这种能力如何随训练获得。

三个依次成立才支持完整主张的命题：

1. **形成次序：** 在固定状态分布上，结果信息的可读出性先达到预注册标准，正确的结果依赖行为随后才达到标准。
2. **功能联系：** 有针对性地改变结果相关表征，会有方向、有选择地改变后续决策，效果超过必要的匹配对照。
3. **性能价值：** 根据独立诊断选择训练位置或监督信号，在相同数据和计算预算下提高未见初态的闭环成功率，或减少达到同一成功率所需的训练成本。

可读出性、因果干预效果和闭环收益分别测量。即使第一条成立，也不能跳过第二、三条。这个问题的工程价值是帮助决定下一笔预算应该用于感知、数据、动作模块还是执行频率。

## 2. 三个候选及取舍

| 候选问题 | 可证伪分歧 | 与现有工作的关系 | 当前取舍 |
| --- | --- | --- | --- |
| 动作结果的信息何时成为实际控制依据？ | 表征尚未形成 / 已可读但未有效使用 / 分支选择正确但执行失败 | 需要超过静态探针、一般 steering 和成功率曲线，建立同谱系训练过程与定向改进的联系 | 推荐主线；现有 checkpoints、事件记录和 StateBank 可复用 |
| 动作模块的小奇异值梯度方向是否包含稀有关键决策的稳定信号？ | 谱尾主要是噪声 / 其中含被常见运动稀释的稳定信号 | Pion 已直接研究 Muon 在 VLA 中的谱噪声问题，必须把事件条件化信号作为新的待检验对象 | 独立备选；需要梯度采样和公平的优化器训练比较 |
| 预训练 VLM 语义能力如何变成机器人控制能力？ | 语义遗忘 / 语义保留但接口读取不足 / 数据没有要求语言 | Knowledge Insulation、APT、Anchor-Align、Goodfire 等已经覆盖许多直接解法 | 用作主线的定位轴；目前不单独提出“加强 alignment”的方法题 |

主线的最小研究对象只包含一种分叉。文本身份、更多交互类型、长任务、其他优化器都可以成为后续外推，第一阶段不同时改变这些因素。

**候选差异来自一条完整的证据链：在同一训练谱系中，定位一种可观察、数据支持的结果依赖决策何时形成，并在未参与定位的数据上验证由该诊断导出的性能改进。** 本次检查的上述段落没有直接给出这条完整证据链；这是一项值得进一步核验的候选空缺。

若最终只得到几个有语义的特征、探针准确率上升或一般 adapter 收益，该问题仍未被充分回答。正式立项前，应进一步复核最近邻全文及公开代码，尤其 FailPatch、Action Atlas、Beyond Task Success 的补充材料。

## 5. 把一个行为分叉做扎实

选择已有可完成的 LIBERO Spatial 抓取放置任务，从抓取尝试附近开始。

| 要素 | 固定方式 |
| --- | --- |
| 语言与成功条件 | 一条原生指令、原生目标与原生成败判据；本阶段保持目标身份固定 |
| 分叉前状态 | 从同一个完整模拟器快照恢复；记录 qpos、qvel、对象状态、控制器状态、时间、观测历史和随机数状态等必要状态 |
| 动作前缀 | 两个分支执行相同尝试前缀，事件点之前一致 |
| 分支结果 | 一支自然抓住；另一支通过可恢复的小扰动出现抓空/滑落，或使用经过匹配的自然失败 |
| 分叉后观察 | 必须反映不同的真实结果。分叉后物理状态本来就不同，不能宣称全过程“相同初态、只有一个标签变了” |
| 有效的行为区别 | 一支继续安全搬运，一支采取合理重新抓取/恢复；具体动作窗口用专家可行性或实际恢复验证 |
| 跨模型输入 | 所有 checkpoints 使用固定状态银行及相同模型可见输入；flow 比较对齐噪声、solver 阶段和 token 位置 |

开始前有四项科学条件要核对：

1. **可观察：** 模型实际接收的图像、机器人状态或已有历史能够区分结果。模拟器 contact flag 不能偷偷作为部署输入。若当前输入物理上不可辨，结论应转向历史/传感限制。
2. **有数据支持：** 确认原训练数据是否包含足够的成功搬运与恢复行为。没有恢复示范时，旧 checkpoint 的失败只能用于分布外诊断；需用各方法共享的恢复数据另设学习实验。
3. **可恢复：** 专家或可信控制器在失败分支能完成任务，扰动没有把目标推到不可达处。控制器仅用于可行性与数据，不混入被评测策略。
4. **此刻应分歧：** 最初一步动作可能在两个分支中都合理。评价一个经过验证的短时窗口，避免把“没有立刻输出相反动作”误标为不会反馈。

还要记录事件发生后何时第一次读取新观测、何时真正执行新预测动作。若期间一直在执行旧 action chunk，尚不能评价网络对新结果的反应。固定执行步数为主协议，较短 chunk 作为执行时序对照，比较推理调用与延迟。

## 6. 三个可以得到 yes / no / inconclusive 的问题

### Q1：结果可读出与正确分支行为之间，是否存在稳定的学习滞后？

每个 checkpoint 测两类量：

- **结果可读出性 R(k)：** 固定容量的线性探针为主，小 MLP 为诊断补充。按 episode/初态组划分训练与验证；控制任务、时间索引、夹爪开度等明显捷径。标签只用于该诊断，不反向污染冻结的无标签候选选择。
- **正确分支行为 B(k)：** 分别报告抓住后继续搬运、失败后合理恢复的比例，以及同一对中两支都处理正确的比例。用实际事件和行为窗口判断，不能以 action L2 变大代替。

在开发集预注册达到标准的规则，冻结后在未查看的初态上比较首次达标的 checkpoint 区间。五个稀疏 checkpoint 只能限定获得能力的区间，不能推断精确训练步数。检验结论是否依赖探针容量或任意阈值。

- **Yes：** 多个独立初态和训练 seeds 上，可读出性较早稳定达标，分支行为在后续区间才达标，且非数据覆盖/可观察性造成。
- **No：** 置信区间足够窄，支持两者没有预先规定的实用差距，或者行为先达标而选定读出量不具解释力。
- **Inconclusive：** 探针测量不足、样本不足、分支不需不同动作，或训练数据/输入前提不成立。

不能把一个线性探针失败解释为表示里绝对没有信息，也不能把“先可读出”直接叫作模型“先理解后行动”。

### Q2：结果相关信息是否通过特定内部通路影响决策？

在每个 checkpoint 内做匹配的 donor patch、候选方向抑制或小幅干预，首先检查自然推理与 no-op hook 一致。保持 input、flow 噪声、solver 阶段、token 范围一致，主要测实际执行前缀。

必要对照：no-op、同结果 donor、异结果 donor、匹配几何但结果不同的可用样本、同幅度随机方向面板，以及无关因素方向。若无法充分匹配几何，结论限定为“结果相关通路”，不宣称隔离了纯粹的稳定抓取变量。使用自然 donor 也不自动消除离分布干预风险。

- **Yes：** 对同一结果因素的干预产生预期方向的分支变化，超过各强对照，对无需切换的阶段影响小，并在独立状态上重复。
- **No：** 有足够检验力时，候选不超过随机/同结果对照，或只造成普遍动作破坏；否定当前候选机制。
- **Inconclusive：** 编辑无效、破坏全局计算、控制不匹配，或统计上无法区分。

跨 checkpoint 的原始激活坐标未必对齐，不能把晚期向量直接移植到早期模型后据此声称“移植了能力”。选择层、方向、剂量及阶段必须只用发现集；正式测量使用未查看的数据。即使局部干预成立，也需要闭环验证，才能判断任务价值。

### Q3：诊断能否指导一种有性能收益的训练改动？

优先检验一个最小改动：在诊断发现的动作读取位置使用小型可训练接口，利用成对结果的正确后续动作进行训练；保留原动作损失。所有方法共享完全相同的状态、动作标签和采样预算。

对 flow policy，可以研究“正确状态—后续动作”与经过可行性检查的错误配对之间的训练约束，采用相同噪声/时间的 denoising 损失估计。它不是已验证算法，也不能把 denoising loss 直接当成精确动作似然。多个动作都有效时，不能随意指定一个为负样本。

最小比较顺序：

| 条件 | 排除的解释 |
| --- | --- |
| 原策略与等预算普通续训 | 改善是否只来自多训练了一段 |
| 同一恢复/分叉数据，普通 BC | 改善是否只来自补齐训练数据 |
| 同参数量、同训练预算的普通 adapter，含未由诊断选择的位置 | 改善是否只来自额外容量或任意位置微调 |
| 仅预测结果的辅助头 | 可读出性提高是否足以提高控制 |
| 诊断位置上的结果依赖训练 | 测试由诊断导出的特定改动 |

早期先运行普通 BC 与最小候选的比较；只有出现超过简单基线的收益，才扩展完整消融。若核心算法与 FailPatch 接近，应加入可复现的 FailPatch 或相应受控实现，明确实现差异；若更频繁重规划是强基线，应报告相同策略调用预算下的结果。

主指标是独立初态上的闭环成功率差，同时报告正常成功保持、恢复成功、误触发恢复、动作调用数、推理耗时和训练总成本。达到预注册成功率所需的数据量/GPU 时间是次指标，所有标签、轨迹采集与预处理成本纳入账目。

- **Yes：** 改进超过预注册的实用幅度和必要对照，并保留正常任务能力；在至少另一个训练 seed/独立任务上得到重复支持。
- **No：** 精度足够的比较排除了有意义的收益，或普通 BC/等容量对照已解释收益。仍可报告局部机制发现，但不能宣传该诊断带来性能改进。
- **Inconclusive：** 区间太宽或成本合同不一致。

例如将 5 个百分点设为最小有用收益，是一种待冻结的设计选择，并非已有结果或通用标准。若以此为阈值，强收益主张应要求置信区间下界超过阈值；上界低于阈值可排除该量级收益，其余保留不确定。统计单元是成对初态/源 episode，采用任务内聚类；不要把帧数或重复噪声数当独立样本。

## 7. 用现有资产开始的最小试跑

首先核对本地/服务器时间轴批次与 checkpoints 可用性、原数据的分支覆盖，以及现有 StateBank 是否有可辨别的抓取结果。当前需求是研究设计，以上是后续执行步骤。

若这些条件成立，探索性 pilot 可采用：

- 两个已有稳定基线的 Spatial 任务；
- 每任务 10 个预事件初态对，总计 20 对；
- 从既有谱系选 5k、10k、25k 三个检查点作为弱/中/强能力位置，明确这是根据已查看结果做的探索性选择；
- 每对两个结果分支，共 `2 tasks × 10 pairs × 2 branches × 3 checkpoints = 120` 条基础 continuation；
- 先检查事件有效性、输入可辨性和行为分叉是否成立，再决定是否增加探针/干预；20 对本身不足以拟合高维表示诊断；
- 探针训练复用独立、有标签且经过支持域检查的训练侧状态；没有合适训练状态时先补齐最小测量数据，不从 pilot 测试对上反复调参。

120 条不包含干预、噪声重复、重新采样及视频人工核对；它只回答该问题是否可测量、是否出现有意义的分歧，不用于最终显著性或普遍结论。

正式实验另设未查看初态、多个策略训练 seeds 和至少一种额外交互/模型的外推，样本量根据 pilot 的成对差异率和预注册最小效果计算。层/剂量/阈值在发现集冻结。成功率接近零或满分时，先检查分支难度和数据支持，不连续调整测试集直到方法显著。

当前没有足够测时依据承诺 GPU 小时。执行前测量单条 continuation、单组表征提取、单个候选训练的时间，按条数和条件数估算成本并设置硬上限；存储只保留需要的层、实际执行前缀和代表视频。沿用项目现有环境，不新建一套评测栈。

## 8. 怎样连接用户关心的其他方向

| 兴趣 | 在本问题中发挥的作用 | 需要增加的独立证据 |
| --- | --- | --- |
| 训练能力如何逐步获得 | 主线：同谱系中结果读出、分支行为、通路使用的时间关系 | 多训练 seed，固定输入分布，细化转变区间 |
| 更好利用 VLM | 定位结果信息在 vision/VLM/interface/expert 哪一段出现和失效 | 任务语义、状态几何、动作可行性分别控制；不能只看 VLM 文本回答 |
| structured input / 特征提取 | 若输入缺关键因素，可测试由已有传感器预测的结构化状态 | 预测值而非模拟器真值进入部署；加入等容量非结构化输入和真实成本对照 |
| 视觉—语言 alignment | 第二阶段将同一反馈分叉迁移到不同目标身份/指称 | 目标语言与成功条件同步，保持物理快照；避免把身份与场景变化混淆 |
| 长任务 | 将分叉处反馈能力作为可检验的子技能，测其对组合任务的贡献 | 长任务独立闭环实验、固定计划器与调用预算；短任务改善不自动推出长任务改善 |
| Muon / 优化效率 | 若证据指向关键事件的梯度信号弱，再研究优化器能否更快获得该能力 | 与采样/数据和学习率预算分离，最终测成功率与墙钟时间 |

长任务还可能受记忆、规划和技能覆盖限制。即使本机制成立，其贡献也可能只覆盖其中一种失败。

## 9. Muon 方向的独立备选

**在 VLA 动作模块的梯度谱中，小奇异值方向是否包含可重复的接触/释放等稀有决策信号？如果包含，保留这些方向是否比统一白化或统一抑制更有利于学会关键行为？**

Pion 的谱分析使“谱尾可能含任务信号”成为需要主动反证的假设。不能以稀有标签与某个方向相关，就说这个方向是被埋没的控制能力。

最小区分：

1. 用等样本量的事件条件 minibatches 与普通 minibatches，在独立数据块上检查尾部子空间/投影的可重复性和信噪比；先处理 minibatch 大小、参数尺度与层差异。
2. 用未参与选方向的关键事件数据检查投影更新是否改善动作约束；再通过闭环验证，避免把训练 loss 降低当成功率。
3. AdamW、Muon、Pion 使用同样的数据、LR 搜索预算、更新次数和模型合同；另外比较简单事件重采样。计算预处理和谱估计成本。
4. 若事件重采样已解释改善，优先接受数据分配解释；若没有稳定尾部信号，停止提出“保留谱尾”的方法。

这个备选更直接面向优化，但通常比复用 checkpoints 的第一轮诊断更贵。主线和备选无需合并成一个庞大系统。

## 10. 什么结果会改变下一步决策

| 观察结果 | 合理结论 | 下一步 |
| --- | --- | --- |
| 实际输入不可辨结果 | 当前传感/历史限制了决策 | 补充可部署的观测或历史；重定义问题 |
| 训练集缺恢复行为 | 不能把失败唯一归因于内部读取 | 共享恢复数据上的普通 BC 是第一基线 |
| 能读出，行为不跟随，候选干预也无特异效果 | 存在诊断落差，当前机制定位失败 | 换测量或候选；停止对该方向作因果命名 |
| 结果干预确实改变分支，但完成率没提高 | 局部功能作用成立，尚不足以产生性能收益 | 查运动执行与下游失败，不宣传性能突破 |
| 改进被普通 BC 或重规划完全解释 | 数据或执行时序提供了足够解释 | 采用简单方案，收缩机制主张 |
| 定位指导的改动在独立状态上超过匹配控制 | 支持解释性诊断具有实际设计价值 | 多 seed、第二种交互、第二模型或长任务外推 |

最值得争取的成果是：一个可重复的能力形成事实、一套能区分原因的实验，以及一项由事实导出的、成本清楚的性能改进。负结果可以终止错误路线，但单个未显著的小样本结果不足以形成强结论。
