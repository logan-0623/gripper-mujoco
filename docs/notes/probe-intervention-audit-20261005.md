# 探针与干预实验的方法审计（2026-10-05）

逐行核对了 `checkpoint_readouts.py`、`contact_subspace.py`、`candidate_controls.py`、`flow_trace.py`，以及旧标签 `pre-restructure` 中的 `recruitment.py` 和 `positive_control.py`，并与 LeRobot SmolVLA 源码（`modeling_smolvla.py`）对照。结论：**此前"可读性不变"和"干预不超过随机"都不能作为结论使用。**

## 1. 纵向可读性 Rₖ 实际是怎么测的

| 项目 | 实际做法 | 问题 |
|---|---|---|
| 特征 | action expert 的 `expert_middle` / `expert_late` 层激活，**在 50 个动作 token 和 3 次噪声上取平均**，每个 flow stage 单独测 | 不含 VLM 侧。取平均会抹掉 token 间的时序信息。Action Atlas（2603.19233）发现，对 token 平均池化后的 SAE 替换回模型，π₀.₅ 成功率从 96% 跌到 8% |
| 报告的 stage | stage 9，即最后一次去噪调用 | 此时 x_t 已接近策略自己的最终动作，而夹爪开合命令与 Contact 高度相关。可读性可能来自"模型自己的动作计划"，不是感知 |
| 状态 | StateBank 中的**演示状态**，不是策略自己 rollout 中的状态 | 5k 模型在自己的状态分布上会犯错，这里测不到 |
| 读出器 | Ridge，α=10 固定，不调参。对二值标签直接做 MSE 回归 | — |
| 指标 | MSE gain = 训练均值预测的 MSE − Ridge 的 MSE | **上限等于标签方差。** Spatial 0–3 验证集的 Contact 患病率为 0.43，方差约 0.246。报告的 0.187–0.200 相当于 R² ≈ 0.76–0.81；只用机器人状态是 0.214，R² ≈ 0.87。**隐藏层不如本体状态**，而且都接近天花板 |
| 样本 | 每个分区 128 个状态；验证集只有 4 个任务、**4 条独立 episode** | 没有 CI，有效样本量约为 4 |

**正确的结论：** Contact 几乎完全由输入中的本体状态（夹爪开度、位置）决定，所以它从 5k 起就可读并不意外。这个实验测的是一个"输入里本来就有"的变量，无法说明能力相关的内部表示是否在变化。另外，指标接近饱和，即使有变化也很难看出来。这与 LLM 中的观察一致：探针准确率在训练早期就饱和，之后的表示变化对它不可见（Reblitz-Richardson, 2026）。

## 2. 三次"干预不超过随机"实际是怎么做的

### 2a. Protocol v3（早期 SFT 谱系）与官方 positive control：设计上无法检验
- **tap 位置：** `action_expert_input` 注册在 `model.action_in_proj` 的输出上；干预 hook 挂在 `action_time_mlp_out` 上。在 SmolVLA 中，这两个模块只处理**带噪动作 x_t 和时间步**（`embed_suffix`）。图像、语言、状态只经由 VLM prefix 的 KV cache 进入 expert。所以这个位置的向量**没有直接的观测通路**。
- **作用时机：** `FinalDenoisingDeltaHook` 只在第 10 次（最后一次）去噪调用时加 delta。Euler 积分的步长是 dt = 1/10，最后一步速度的改变对最终动作只有 0.1 倍的影响。
- **作用形式：** 同一个池化后的 [B, D] 向量加到全部 50 个动作 token 上，无法表达"在某个时刻改变夹爪"这类与时间相关的变化。
- **结论：** 在这种设置下，目标方向和随机方向都只能产生很小的扰动。"不超过随机"是设计导致的，不是关于模型的结论。这些数据应作废，不能计为负结果。

### 2b. 自训练谱系的 Contact 子空间：位置合理，但力度和样本不足
- **位置：** expert 中层和后层。这些层通过 cross-attention 读取了观测信息，位置是合理的。
- **方向：** 用 Ridge 读出方向。读出方向不一定是模型"写入并使用"的方向。
- **操作：** 去掉该方向上 50% 的投影（dose 0.5），作用于全部 10 个 stage，只作用在一层。
- **规模：** 32 个状态 × 3 次噪声，4 条独立 episode，只测离线动作差。
- **问题：** 秩 1、半强度、单层。Contact 信息在 prefix（本体状态）中有冗余，模型可以绕过被抑制的方向。要检验"是否使用"，应当用 LEACE 或均值投影在所有层擦除（Belrose et al., 2023；Dobrzeniecka et al., 2025），或者用跨状态的激活替换（activation patching）。
- **结论：** 不确定，不能算作负结果。

### 2c. 无标签方向（`formation_0`）与 SAE
效应是真实的离线信号，量级为 1e-3 RMS，但与闭环行为之间的关系还没有建立。这部分仍然有效。

## 3. 修正后应该怎么测

1. **可读性：**
   - 以本体状态加时间为条件，测隐藏层的增量。
   - 目标换成输入中没有直接给出的变量，例如物体相对夹爪的位姿、物体是否在手中且离开桌面、任务进度、下一步应执行的动作类别。
   - 指标从准确率换成**脆弱度**（fragility，即探针准确率开始崩溃时的噪声水平）或分类间隔。这两个量在准确率饱和后仍会变化。
   - 用 episode 级 CI，验证集至少 10 条独立 episode。
2. **干预位置：** expert 各层，或 VLM 与 expert 之间的 KV。逐个 flow stage 扫描，因为扩散模型的经验是不同去噪步负责不同属性。
3. **干预方式：**
   - 跨状态替换（例如用接触状态的激活替换非接触状态的激活）。
   - LEACE 全层擦除。
   - 剂量—反应曲线。
   - 闭环评测作为最终判据。
